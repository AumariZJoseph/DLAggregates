SEO Requirements
SEO is a primary objective of this build — the site must rank for local St. Lucia construction searches and support the Phase 2 monthly SEO work described in the marketing plan. Codex should implement everything below as part of the initial build.

1. Keyword Strategy
Target local, intent-driven keywords. Primary clusters:

Equipment Rental:

"equipment rental St. Lucia", "heavy equipment rental St. Lucia"

"excavator hire St. Lucia", "backhoe rental St. Lucia", "bulldozer rental St. Lucia"

"roller/compactor rental St. Lucia"

Aggregates & Materials:

"aggregates St. Lucia", "aggregate supplier St. Lucia", "aggregates Babonneau"

"concrete blocks St. Lucia", "blocks Babonneau", "building blocks St. Lucia"

Add product-specific aggregate terms only after the catalogue is confirmed by DL.

Haulage & Transport:

"heavy equipment haulage St. Lucia", "container haulage St. Lucia"

"construction material delivery St. Lucia", "construction waste disposal St. Lucia"

Site Works:

"demolition services St. Lucia", "site preparation St. Lucia", "grading and clearing St. Lucia", "desilting St. Lucia"

Geo-modifiers: Combine core terms with locations — "Castries", "Babonneau", "Gros Islet", "Vieux Fort", "Rodney Bay", "island-wide", "St. Lucia".

Each service page should own one primary keyword cluster (no cannibalization) with secondary variants in body copy. Do keyword research at build time to confirm volumes and refine.

2. On-Page SEO
Title tags: Unique per page, ≤60 characters, lead with primary keyword + location + brand (e.g., Excavator & Heavy Equipment Rental St. Lucia | DL Equipment).

Meta descriptions: Unique per page, 140–160 characters, include primary keyword, a value prop, and a CTA.

Heading hierarchy: One <h1> per page containing the primary keyword; logical <h2>/<h3> structure for sub-services.

URL structure: Clean, keyword-rich, lowercase, hyphenated (e.g., /equipment-rental/, /aggregates-materials/, /haulage-services/, /projects/, /blog/). No query strings or IDs for main pages.

Internal linking: Every service page links to related services, the Contact page, and relevant Projects/Blog posts. Home links to all top-level services. Use descriptive anchor text (not "click here").

Image alt text: Descriptive, keyword-relevant, but natural — e.g., Excavator available for rental in St. Lucia – DL Equipment & Aggregates.

3. Technical SEO
sitemap.xml — auto-generated, submitted to Google Search Console; include all pages and blog posts.

robots.txt — allow crawling, reference sitemap, block admin/CMS paths.

Canonical tags on every page to prevent duplicate content.

SSL/HTTPS — enforce HTTPS, redirect HTTP → HTTPS.

301 redirects — if the existing domain has any historical URLs, map them to the new equivalents; otherwise ensure clean URL structure from launch.

Structured data (JSON-LD):

LocalBusiness (or GeneralContractor subtype) on the Home page — name, address, phone, email, opening hours, geo-coordinates, areaServed: St. Lucia, sameAs (Facebook URL).

Service schema on each service page.

Product schema on confirmed aggregate and concrete-block listings where appropriate.

BreadcrumbList on interior pages.

BlogPosting on blog articles; Article author/date metadata.

Core Web Vitals: Lazy-load images below the fold, compress and serve images in WebP/AVIF, minify CSS/JS, defer non-critical scripts, target LCP < 2.5s, CLS < 0.1, INP < 200ms.

Mobile-first: Responsive layout, tap targets ≥48px, no horizontal scroll, viewport meta tag.

Hreflang: Not required (single-locale site, English only).

Analytics: Google Analytics 4 + Google Tag Manager installed site-wide; Google Search Console verified and sitemap submitted.

404 page: Custom, branded, with links back to key pages.

5. Content SEO
Blog architecture: Each post targets a long-tail keyword or project update; posts include internal links to relevant service pages, BlogPosting schema, author, publish date, and a clear CTA.

Projects section as SEO asset: Each project entry should be a standalone page (not just a gallery image) with descriptive copy, location, scope of work, and relevant service links — this creates indexable, keyword-rich content that supports service pages.

Service page copy: 300–600 words per service page, written for humans first, with primary/secondary keywords woven in naturally. Include FAQ blocks where useful (with FAQPage schema) to capture "People Also Ask" visibility.
